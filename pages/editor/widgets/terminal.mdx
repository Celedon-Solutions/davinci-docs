title: Terminal
description: Run local project commands through the Local File Bridge
---

Terminal provides command-line access to a project through the Local File Bridge.

<Note>
  Terminal is available only while the Local File Bridge is connected. When the bridge is unavailable, Terminal is omitted from widget menus and panel navigation.
</Note>

Use `Cmd/Ctrl + Shift + T` to open Terminal. The shortcut continues to open Terminal if you move it between panels.

## Panel placement

Terminal lives in the [Right Panel](/pages/editor/panels/right-panel) by default. Drag it between panels or use its context menu to move, order, hide, or restore it.

Terminal is separate from output terminals embedded in individual Code or simulation views. Those terminals display output for their containing workspace tab; this panel connects to the local project environment.
