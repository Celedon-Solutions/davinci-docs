## Overview

Files and references bring source material into a Davinci project. They help the model stay connected to technical documents, specifications, diagrams, spreadsheets, CAD exports, reports, and other source data.

Use files when you need to store source material in a project. Use reference objects when you need that material to be visible, searchable, cited, and usable by the Davinci Agent.

## Uploading Files

You can add files by:

- Dragging files into the Editor.
- Using the upload button in the Library.
- Uploading files from Project Settings > Files.
- Pasting supported files into Agent chat.

Uploaded files are stored with the project and can be represented as reference objects in the Library.

Davinci supports large uploaded files, including large spreadsheets and source datasets. Some file types can be converted into model objects, while others are stored as Reference objects for browsing, citation, and Agent context.

For file limits and storage management, see [Project Settings > Files](/pages/editor/project-settings/files). For Excel import behavior, see [Tables](/pages/modeling/objects/tables). Word and PowerPoint files open as editable [documents](/pages/modeling/objects/documents#from-word-documents) and [slides](/pages/modeling/objects/slide#importing-powerpoint), or upload as PDFs; Davinci asks which when you drop them.

## Reference Objects

Reference objects are model objects that point to source material. They can represent PDFs, images, raw files, converted documents, spreadsheets, or other uploaded data.

Use reference objects to:

- Browse source material in the Editor.
- Give the Davinci Agent source context.
- Ground generated model content in evidence.
- Track where a requirement, attribute, or object came from.
- Maintain citation metadata for documents and reports.

See [Reference object](/pages/modeling/objects/reference) for field-level details.

## Editing Text Files

Text-based reference files, such as `.txt`, Markdown, JSON, YAML, XML, CSV, and source code files, open in a text editor when you view them. If you can edit the project, you can type directly in the file.

Your changes save as you type:

- After a short pause in typing, and at least every five seconds while you keep typing.
- Right away when you press `Ctrl/Cmd + S`, click outside the editor, close the tab, or leave the page.

The editor toolbar shows **Saving...**, **Saved**, or **Not saved**. A save that fails is retried automatically. When you reopen the file, it shows exactly what you typed, even if you closed it while a save was still in progress.

Edits are saved to the current branch's working copy of the file, the same way code edits are, so commit them like any other change. If you type the file back to its committed text, the file returns to its committed version.

<Note>The text editor is read-only for viewers, in commit and merge views, and for references included from another project.</Note>

## Source Grounding

When the Agent uses a reference to create or update model objects, Davinci can create reference relationships back to the source object. These relationships help users understand why a model element exists and where its supporting evidence came from.

For PDFs and long documents, reference handling can include source-page or source-window context so reviews and generated content can point back to relevant evidence.

## Using `@` References

Use `@` to mention model objects in chat, documents, tables, code, equations, and other supported editors. This helps connect text, calculations, and Agent prompts to concrete model objects.

See [The @ System](/pages/modeling/overview/mentions) for syntax and examples.

## Downloading A Package As A Zip

To get every file under a package at once, right-click the package in the Index and choose **Download as Zip**, or open the package's **Export** menu and choose `ZIP`. The zip contains the package's reference files and code objects, with nested packages as folders. Link-only and external references have no file and are skipped. If any file cannot be downloaded, the zip includes an `_download-errors.txt` listing what was missed.

## Managing Files

Use [Project Settings > Files](/pages/editor/project-settings/files) to inspect uploaded files, active/inactive status, storage usage, and cleanup options.

Use the Library in the Index to organize active reference objects alongside the model.
