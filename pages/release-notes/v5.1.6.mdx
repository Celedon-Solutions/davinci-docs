## Version 5.1.6 - Task Card & Billing Fixes

This patch improves Team Task Card reliability, billing-cycle handling, and compact workspace layouts.

### Improvements

- Administrators can filter users by the Max subscription tier
- Compact chat layouts now prevent persona controls and model labels from overlapping
- Branch deletion prompts now clearly identify the current branch

### Bug Fixes

- Fixed errors on Team Task Card pages and restored reliable searching, filtering, sorting, and pagination
- Fixed Stripe-backed checkout and subscription updates so billing-cycle dates are processed reliably
