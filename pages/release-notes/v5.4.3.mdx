## Version 5.4.3 - Public Project Fixes

This patch fixes viewing public projects without an account and contains minor fixes.

- Visitors without an account can now load a public project's CAD, simulation results, and history, for example after following a published page into the project
- Public project views no longer include the project's secrets, MCP servers, or other credentials
- A trade can now be restored together with the target it drives, such as in a rollback, undo, or import
