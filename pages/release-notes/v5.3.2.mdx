## Version 5.3.2 - Default Personas, Slides & Performance

This patch adds default personas for new chats, copy and paste on slides, and broad database performance improvements.

### Agent Personas

- Added a [default persona](/pages/editor/project-settings/persona-settings#default-persona-for-new-chats) for new chats: project owners and admins can set a **Project Default**, and each user can set **My Default**
- Persona settings now use dropdown menus

### Slides & Source Control

- Added copy and paste for slide elements
- Fixed right-click after clicking and dragging on a slide
- Updated colors in Source Control change tables
- The Git Sync section of Source Control is now hidden unless an administrator enables it

### Browser

- The quick project list on the Home page now shows the projects you opened most recently
- Improved contrast in light mode
- Updated avatar handling

### Performance & Reliability

- Major performance improvements for database operations across the platform
- Fixed MCP servers that use OAuth without a configured credential method
