## Version 5.1.1 - Engineering Workflow Updates

This patch improves engineering file workflows, agent image tools, and simulation and card capabilities.

### Highlights

- Improved STEP assembly imports and batch file uploads
- Added image-region selection for focused chat context and an agent tool for editing images
- Added simulation safety factors and improved simulation limit feedback
- Improved PCB symbol and footprint search reliability
- Refined card and artifact-reference interactions

### API Additions

- Card list endpoints now support deadline and effort filters, including cards with no deadline or effort
- Card API responses now include author, close-time, and tag information where applicable
